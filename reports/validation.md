# Validation report (Phase 3)

Generated by `make backtest` (`python -m gauges.backtest --apply`). All scores are point in time: each day uses only data public by then, ranked against its own trailing history. Weights are not fitted to the sample, so no walk-forward tuning was needed.

**Caveats.** Forward windows overlap, so daily ICs overstate significance; t-stats use non-overlapping windows. Constituent breadth (net highs/lows, McClellan, % above 200d) uses today's S&P 500 members and carries survivorship bias. The AI basket is today's selection applied backwards, so AI trend and breadth inputs carry hindsight bias; G3/G4 are scored against SMH. ICE BofA spreads only exist from 2023-10-16 and several AI and earnings series start in 2023-2025, so those indicators sit below the 5-year threshold and are kept with a low-confidence label rather than judged.
